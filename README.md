# Reportaje: ¿Cuánta agua residual entra al humedal de Xochimilco?

Análisis regional del drenaje y descargas en el sistema Xochimilco–Tláhuac–Chalco. Hasta 270 millones de litros diarios de presión hídrica acumulada. Causa principal de la extinción del ajolote mexicano.

## Contenido

1. Estadísticas clave: 1,373 descargas, 20,000+ conexiones, 1.8M personas
2. Contexto histórico: 50 años de urbanización sobre el lago
3. Impacto ecológico documentado
4. Estimación regional de conexiones contaminantes
5. Coordenadas de zonas críticas verificadas
6. Cálculo hídrico: 180M–270M litros diarios
7. Mega colectores del sistema
8. Marco legal: delitos ambientales tipificados
9. Actores gubernamentales responsables
